About Turtle Graphics

Turtle Graphics allows users to make interactive art with math and code. It was codeveloped by MIT professors, children, and their schoolteachers in the 1960s and ’70s.

Users control the movement of a little avatar (nicknamed a “Turtle”) that moves through space a bit like a person does, using only four commands: move forward, move back, turn left, and turn right.

This simple design constraint lets people reason about math and engineering problems using the same everyday thinking we use to walk to a friend’s house.

This familiarity makes it straightforward to break “hard” problems down into small, recognizable parts. The results on student progress can be remarkable.

(It’s also a lot of fun.)

About the Lua Language

Over the years, multiple versions of Turtle Graphics have been built, using different programming languages.

I built luaturtle.com, which uses the Lua language, because of its widespread use in game development. World of Warcraft, Roblox, Crysis, and Balatro all use Lua in one way or another.

Lua is very simple, and an excellent language for beginners.

Because of the strong similarities between Turtle Art and videogames in general, this makes Lua Turtle Graphics an ideal fit for any student with a preexisting interest in gaming or game development.
